# 内容归属、重复与修改后覆盖检查

## 判断边界

- 按当前模板的章节用途确定归属，不写死章节编号，不要求补建已经删除或不适用的章节。
- 同一事实只在所属位置完整定义。概览用途、图中必要动作、风险触发条件及不同接口各自的异常行为，可以有必要重复。
- 表后处理说明优先合入对应处理表；图旁的执行步骤优先画入图中；风险集中到风险表，依赖图旁不再次汇总接口契约。
- 图例、阅读说明和不能由图表达的必要约束不因位于图旁就违规；先确认其作用与归属。
- 比较的是对象、条件、动作、时机、结果及失败行为。相同标识符或相似措辞不足以证明同一事实。
- 保存失败与消息入队失败、不同任务的约束、不同配置值下的分支，不能只因后续都打印日志而合并。

## 脚本使用

运行 `scripts/validate_detailed_design_content.py`，修改前保存一份本地基线；修改后可用 `--before` 辅助核对。

```text
python -X utf8 <技能目录>/scripts/validate_detailed_design_content.py <详设路径>
python -X utf8 <技能目录>/scripts/validate_detailed_design_content.py <详设路径> --before <修改前副本> --json
```

- 默认最短匹配文本为 32 个规范化字符，相似度为 0.88；可用 `--min-chars`、`--similarity` 调整。阈值只影响候选召回，不代表可删除。
- 支持多个文件，各文件独立扫描；`--before` 只接受一份当前文档。JSON 保留全部候选及原文、行号、章节、小标题和上下文。
- `D004` 的主位置来自旧文件，关联位置来自新文件；其他规则的两个位置都属于当前文件。
- 每段重复候选只展示最相近的一处证据；它不是所有重复位置的完整清单。删除候选前仍须检索同一事实的其余位置。
- 退出码 `0` 表示未发现候选，`1` 表示存在待复核项，`2` 表示参数或读取错误。脚本只读，不生成删改补丁。

| 规则 | 发现什么 | AI 必须判断什么 |
|---|---|---|
| D001 | 正文与另一段正文、表格行或图中文字相同、包含或相似 | 是否同一事实；是否包含独有条件；是否为必要重复 |
| D002 | 时序或依赖章节含独立业务说明 | 是否应入图、回到接口定义或进入风险表；不能直接认定为重复 |
| D003 | 同一说明块的表格后紧接处理文字 | 是否应合入处理表；是否为不可省略的补充 |
| D004 | 旧版说明被删除、改写或移到其他上下文 | 必要信息在新版哪里保留；是否改变条件、对象、数值、否定或失败语义 |

## AI 复核及修改

1. 阅读候选两处的完整表头、条件、所属函数或事件、图中分支及相邻文字，确认它们是否表达同一事实。
2. 判为“删除重复”“合并独有信息”“移动归属”“保留必要内容”或“内容冲突”；说明依据，不以分数作结论。
3. 删除前指出必要信息的保留位置。重复段落多出的条件或异常分支先合入所属位置；无保留位置时不得作为重复直接删除。
4. 两处说法冲突时回到已确认需求或源码核对，不能任选一处当成权威。未能确认的冲突单独报告。
5. 修改后复跑并核对改动差异；逐项检查被删除或改写的条件、时机、取值、状态及失败行为，确保没有因精简丢失约束。

核对表只存在于校验报告，不复制到正式详设；仅记录本次处理的候选，不要求给整篇文档逐句编号。

| 候选位置 | 判断 | 操作或保留理由 | 必要信息保留位置 |
|---|---|---|---|
| 文件与行号 | 删除重复/合并/移动/保留/冲突 | 结合完整上下文的理由 | 当前文件的位置，或尚未确认的缺口 |

## 自动检查的局限

- 脚本使用轻量 Markdown 扫描，保留段落、列表、表格行及 Mermaid 动作和分支文字；保留数值、单位、否定词和 C 标识符。
- 不按业务文字扫描 Frontmatter、HTML 注释、普通代码块、接口用途和概览；必要的风险描述不参加重复候选比较，但旧版风险删除会由 `--before` 提示。
- 表格与图之间、不同表格之间的重复不自动报为 D001，避免把必要的多种表达形式全部标记；AI 仍须核对它们是否重复定义完整契约。
- 无法可靠解析所有 Markdown 扩展、外部图片、复杂 Mermaid 标签、跨段推理或同义改写；不会验证 API 实现或实际运行效果。
- 改写后没有字面匹配不代表信息丢失；找到相同文字也不代表上下文和语义一致。`--before` 仅为复核提供线索。
- 不设永久忽略关键词来掩盖误报，不凭候选自动删除，不为追求零候选改写正确内容。
- 交付分别说明脚本候选数、AI 判断和未完成的检查；不能用“脚本通过”表示全文无重复或语义完整。
