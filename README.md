# change-check · 变更校验工具

项目仓库：[chiyugui001/change-check](https://github.com/chiyugui001/change-check)。

检查代码、知识库、配置和普通文档的变动。日常执行脚本检查；提交前执行必检脚本和独立 AI 审查，支持按声明的文件或模块增量复用结果。按需运行，无需后台服务。

## 安装

准备 Windows、Python 3.11+、Git，以及已登录的 Claude Code 或 Codex CLI。解压独立包或克隆仓库，在要检查的项目目录中运行：

```powershell
& 'C:\tools\change-check\install.ps1'
```

项目路径留空使用终端当前目录。向导选择检查模块、编辑平台、审查器和模型；基础规范、模板、校验脚本已随包提供。Python 依赖安装需要联网。

| 用途 | 检查模块 |
|---|---|
| 代码、配置和普通说明文档 | `code,config,document` |
| 工程知识库，也包含代码和配置 | `knowledge,code,config` |

自动选择依据项目内的规范目录；其他目录结构可在向导中选择知识库模块。已有项目规范和本机技能优先，缺省使用随包资源；明确指定的路径缺失时报错。

## 使用

```powershell
$cc = 'C:\tools\change-check\change-check.ps1'
& $cc check --changed
& $cc review --changed
& $cc doctor
```

`check` 执行脚本；`review` 独立调用配置的 AI 客户端。安装 Git 钩子后，提交前检查暂存内容，失败则阻止提交。AI 客户端钩子须按宿主要求信任并实际验证；本地 Git 钩子可被跳过，不能替代服务端门禁。

## 范围

| 模块 | 当前覆盖 |
|---|---|
| 知识库 | 文档属性、链接、模板、文案候选、未决事项关联及语义审查 |
| 代码 | C 基础词法规则、Python 语法；其他语言、编译和测试使用项目配置的检查命令 |
| 配置与普通文档 | 配置解析、重复键、冲突标记和围栏；提交时补充 AI 审查 |

脚本通过不代表编译、设备验证或语义正确。真实客户端事件、实际模型效果仍需在部署环境验收。

## 目录与维护

| 目录 | 内容 |
|---|---|
| `src/`、`tests/` | 工具源码与测试 |
| `文档/` | 使用指南、设计、覆盖清单、验证和发布说明 |
| `packaging/` | 打包程序与来源配置示例 |
| `resources/` | 自动生成的规范、模板、脚本及来源校验和，禁止手工维护 |
| `dist/`、`.venv/` | 本机发布产物与运行环境，不提交 |

维护者只修改原规范和技能脚本，发布时自动生成副本。参见[使用指南](文档/使用指南.md)、[发布指南](文档/发布指南.md)、[验证记录](文档/验证记录.md)。
