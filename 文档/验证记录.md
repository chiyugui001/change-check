Windows 终止进程树存在系统耗时，超时用例按“调用返回后不再写入”判定，不把终止完成前的写入误判为残留进程。

## 5. 通用模块验收

| 范围 | 本地验证内容 |
|---|---|
| 普通项目 | 无知识库模板/技能仍可登记、检查、安装与卸载；普通 Markdown 不要求 Frontmatter |
| 文件检查 | C 规范样例、Python 语法、配置重复键、普通文档围栏；Git/非 Git/全量检查中的未覆盖文件阻断 |
| 项目命令 | 暂存文本与二进制隔离；失败、缺程序和改写输入阻断；提交阶段角色必检 |

| 规则边界 | C 为词法检查；编译和测试需配置项目真实命令；不宣称完整 C 语法或路径分析 |
| 运行边界 | CLI 及 Git 在隔离环境实测；真实宿主事件与真实模型仍按第 4 节验收 |
